## Featured Projects

### 🧬 Cipheak - Constructed Language Generator

> *The only full-stack conlang builder inspired by Esperanto grammar*

Create complete artificial languages from scratch: phonetics, alphabet, vocabulary, morphology, grammar rules, and **interactive lessons with exercises**. Every generated language is a fully functional linguistic system - not just random words, but a learnable language with coherent internal structure.

**Stack:** Azure Functions · Cosmos DB · React · Vite · Node.js (Serverless)

---

### 🤖 [SAI CLI](https://sai.esperanto.co/cli) - AI Coding Assistant for the Esperanto Community

> *sai.esperanto.co/cli*

A terminal-based AI coding assistant built in **Rust**, designed specifically for the Esperanto tech community. Think Kiro CLI or Claude Code, but in Esperanto. Installable in one line:

```bash
curl -fsSL https://sai.esperanto.co/install.sh | bash
```

**Stack:** Rust · Azure OpenAI (GPT-5) · Azure Functions · Shell

---

### 🎸 [Ludilo](https://ludilo.esperanto.co) - AI Music Learning Platform

> *ludilo.esperanto.co - Beta*

Upload any audio and get stems separated (vocals, guitar, bass, drums), converted to MIDI, and rendered as interactive sheet music. Powered by **Demucs** and a **custom-trained ONNX model** (85.4% F1 on note detection), with a **distributed GPU node network** where operators earn fractions of user payments for contributing processing power.

**Stack:** Python · PyTorch · ONNX Runtime · Demucs · Azure Functions · Azure Container Registry · Azure Container Instances · Cosmos DB · Blob Storage · React + Vite

---

### 🎙️ Transkribi - Distributed Transcription Platform

> *transkribi.esperanto.co - In development*

Serverless transcription platform built for **students and conference attendees**. Transcribes lectures and talks using multiple AI models, then generates study-ready materials. Uses the **same distributed node model as Ludilo** - nodes earn credits by contributing processing power.

- 21 endpoints · JWT + Google OAuth · Roles: user / noder / manager
- Credit system (free + paid) · Admin dashboard · Distributed processing

**Stack:** Python · Azure Functions · Azure Cosmos DB · Azure Blob Storage · Azure Application Insights · Whisper

---

### 🧠 [EEG Hyperscanning in Tango](https://github.com/Doniben/eeg-hiperescaneo-tango) - Neuroscience Research

> *Simultaneous EEG of two dancing brains*

Signal processing scripts for analyzing **interbrain synchrony** between tango dancers. Part of a Master's thesis in Neuroscience (Katheryn De Alba). Data from OpenBCI + OpenViBE, 19-channel recordings per subject.

**Stack:** Python · Shell · BrainVision format · OpenBCI

---

### 📚 [Calibre Intelligent Library](https://github.com/Doniben/calibre-intelligent-library) - Semantic Book Search

> *AI-powered plugin for your personal library*

Calibre plugin that adds **semantic search** - find books by concept, not just title or author. Search inside chapters, get AI recommendations, fully portable across machines.

**Stack:** Python · Semantic embeddings
