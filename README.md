## Featured Projects

### 🧬 [Cipheak](https://github.com/Doniben/cipheak-backend) — Constructed Language Generator
> *The only full-stack conlang builder inspired by Esperanto grammar*

Create complete artificial languages from scratch: phonetics, alphabet, vocabulary, morphology, grammar rules, and **interactive lessons with exercises**. Every generated language is a fully functional linguistic system — not just random words, but a learnable language.

**Stack:** Azure Functions · Cosmos DB · React · Vite · Node.js (Serverless)

---

### 🤖 [SAI CLI](https://github.com/Doniben/sai-cli) — AI Coding Assistant for Esperanto Community
> *sai.esperanto.co/cli*

A terminal-based AI coding assistant built in **Rust**, designed specifically for the Esperanto tech community. Think Kiro CLI or Claude Code, but for Esperantists building software. Installable in one line:

```bash
curl -fsSL https://sai.esperanto.co/install.sh | bash
```

**Stack:** Rust · Shell · Azure AI

---

### 🎸 [Ludilo](https://github.com/Doniben/ludilo-backend) — AI Music Learning Platform
> *ludilo.esperanto.co · Beta*

Upload any audio → get stems separated (vocals, guitar, bass, drums) → converted to MIDI → interactive sheet music. Powered by **Demucs** and **Basic Pitch**, with a **distributed GPU node network** where node operators earn fractions of user payments for contributing processing power.

**Stack:** Python · Azure Functions · Cosmos DB · Blob Storage · NVIDIA GPU Worker · React + Vite

---

### 🎙️ Transkribi — Distributed Transcription Platform
> *transkribi.esperanto.co · In development*

Serverless transcription platform built for **students and conference attendees**. Transcribes lectures and talks using multiple AI models, then generates study-ready materials from the content. Uses the **same distributed node model as Ludilo** — nodes earn credits by contributing processing power.

- 21 endpoints · JWT + Google OAuth · Roles system (user / noder / manager)
- Credit system (free tier + paid) · Admin dashboard

**Stack:** Python · Azure Functions · Cosmos DB · Blob Storage · Application Insights

---

### 🧠 [EEG Hyperscanning in Tango](https://github.com/Doniben/eeg-hiperescaneo-tango) — Neuroscience Research
> *Simultaneous EEG analysis of two dancing brains*

Signal processing scripts for analyzing **interbrain synchrony** between tango dancers. Part of a Master's thesis in Neuroscience (Kátheryn De Alba). Data from OpenBCI + OpenViBE, 19-channel recordings per subject, formatted for BrainVision.

**Stack:** Python · Shell · BrainVision format

---

### 📚 [Calibre Intelligent Library](https://github.com/Doniben/calibre-intelligent-library) — Semantic Book Search
> *AI-powered plugin for your personal library*

Calibre plugin that adds **semantic search** — find books by concept, not just title. Search inside chapters, get AI recommendations, fully portable across machines.

**Stack:** Python · Semantic embeddings
